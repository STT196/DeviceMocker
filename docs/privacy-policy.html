DeviceMocker Privacy Policy

Last updated: June 5, 2026

DeviceMocker is a Windows desktop application for simulating device input and testing POS printer, cash drawer, serial, TCP, UDP, and HTTP workflows.

Information DeviceMocker Collects

DeviceMocker does not require user accounts and does not collect personal information for sign-in, marketing, or analytics purposes by default.

Local Data Storage

DeviceMocker may store application settings, profiles, emulator configuration, and user-created testing data locally on your Windows device so the app can remember your preferences and workflows.

Network and Device Features

DeviceMocker includes optional features that can send or receive user-provided data over serial ports, TCP, UDP, and HTTP. These actions occur only when the user configures and uses those features. DeviceMocker does not automatically transmit personal information to the developer.

Analytics and Telemetry

DeviceMocker does not include built-in advertising, third-party analytics, or telemetry collection by default.

Data Sharing

The developer does not sell personal information collected through DeviceMocker. Any data sent to external systems is controlled by the user through the app's testing and emulator features.

Your Choices

You can stop using DeviceMocker at any time. You can also remove locally stored app data by uninstalling the app and deleting remaining local application files, if any.

Contact

For questions about this privacy policy or DeviceMocker, please visit the project repository: https://github.com/x1n-Q/DeviceMocker
