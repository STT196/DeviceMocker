# DeviceMocker Wiki

Welcome to the **DeviceMocker** wiki — the complete guide to using and extending the hardware input device simulator.

## What is DeviceMocker?

DeviceMocker is a Windows desktop application that simulates hardware input devices (barcode scanners, RFID readers, weighing scales, card readers, serial devices) so developers can test their software without real hardware.
